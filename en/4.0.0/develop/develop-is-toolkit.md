# Introduction

The WSO2 Financial Services IS Accelerator supports two approaches for extending and implementing its functionalities, as illustrated in the image below.

![IS\_Accelerator\_Extensions](/en/4.0.0/assets/images/OB_Flows_with_OpenAPI_Extensions-abb5891212d63002a78b22ce189933e9.png)

### OpenAPI based extensions[​](#openapi-based-extensions "Direct link to OpenAPI based extensions")

With the release of Open Banking 4.0, it has introduced OpenAPI based extensions such that the toolkit developer can implement Open Banking specification requirements in their preferred programming language. And the custom developed extensions can be deployed externally and tested separately without restarting the WSO2 servers. The OpenAPI extension can be found from [here](/en/4.0.0/references/accelerator-extensions-api/.md).
