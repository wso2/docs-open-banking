# Security Guidelines for Production Deployment

When deploying WSO2 Open Banking in a production server, make sure to comply with the following common security guidelines for production deployment. 

 - For WSO2 Open Banking Identity Server Accelerator refer [WSO2 Identity Server Security Guidelines for Production Deployment](https://is.docs.wso2.com/en/6.1.0/deploy/security/security-guidelines-for-production-deployment/)
 - For WSO2 Open Banking API Manager Accelerator refer [WSO2 API Manager Security Guidelines for Production Deployment](https://apim.docs.wso2.com/en/4.2.0/install-and-setup/setup/deployment-best-practices/security-guidelines-for-production-deployment/)
 - For WSO2 Open Banking Business Intelligence Accelerator refer [WSO2 Streaming Integrator  Security Guidelines for Production Deployment](https://si.docs.wso2.com/latest/setup/production-checklist/#securing-the-wso2-integrator-si)
