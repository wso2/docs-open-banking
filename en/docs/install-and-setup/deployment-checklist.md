# Deployment Checklist

When deploying WSO2 Open Banking in a production server, make sure to go through the following checklists to guide you in setting up your production environment.

- For the WSO2 Open Banking Identity Server Accelerator, see the [WSO2 Identity Server Deployment Checklist](https://is.docs.wso2.com/en/6.1.0/deploy/deployment-checklist/).
- For the WSO2 Open Banking API Manager Accelerator, see the [WSO2 API Manager Deployment Checklist](https://apim.docs.wso2.com/en/4.2.0/install-and-setup/setup/deployment-best-practices/production-deployment-guidelines/).
- For WSO2 Open Banking Business Intelligence Accelerator refer [WSO2 Streaming Integrator Deployment Checklist](https://si.docs.wso2.com/latest/setup/production-checklist/)
